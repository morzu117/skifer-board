# Design — Skifer Board

Maquettes et design system dérivés du plan de développement (31 octobre 2026).

| Fichier | Contenu |
|---|---|
| `DESIGN-SYSTEM.md` | Principes, couleurs, typographie, espacements, composants, contenu |
| `RULES.md` | Règles non négociables et marche à suivre si le technique diverge |
| `tokens.css` / `tokens.json` | Valeurs du design system (variables CSS / données) |
| `design-system.html` | Page de référence visuelle (ouvrir dans un navigateur) |
| `mockups/` | Cinq écrans HTML autonomes, liés entre eux |

Écrans : `01-exploration`, `02-analyses`, `03-editeur-dashboard`, `04-consultation`, `05-promotion-environnements`.

Les données des maquettes sont fictives. Les polices IBM Plex se chargent depuis Google Fonts ; sans réseau, la police système prend le relais.
