# skifer-board

> **Self-hosted, agentic self-BI on top of the [skifer](https://github.com/morzu117/skifer) semantic layer.**
> Dashboards as YAML, ad-hoc exploration without SQL, a chat that pins its answers to a dashboard,
> and a reporting suite — with no commercial BI platform in the loop.

**Status: design phase.** No runnable code yet. The roadmap and the contract expected from skifer
are written and open for discussion; the first implementation plan is next.

---

## What it is

skifer centralizes **transformation** and the **semantic layer** (metrics, dimensions, joins,
calendars, certification, evidence) declaratively. skifer-board is the **consumption layer** on top
of it:

| Capability | How it works |
|---|---|
| **Dashboards as YAML** | A tile is a `SemanticQuery` (model, metrics, dimensions, filters, period — never SQL) plus a visualization spec. Generated by an agent, edited by a human, versioned in git. |
| **Provenance on every tile** | Each tile shows the evidence skifer returned: executed SQL hash, metric definition hashes, certification status, data age, policy decision. |
| **Ad-hoc explorer** | Pick a model, dimensions, metrics, filters → chart → pin to a dashboard. No LLM involved. |
| **Agentic** | Chat → `SemanticQuery` + visualization → pin. The LLM proposes names; skifer builds the SQL deterministically. |
| **Reporting suite** | Schedules, PDF/PNG exports, subscriptions, metric alerts. |
| **KPI packs** | Declarative packs per domain: a template semantic model plus dashboards, explorations and alerts. |

## Principles

- **Never emits SQL.** Everything the board asks for is a `SemanticQuery` resolved by skifer.
- **One boundary.** The board talks to skifer over HTTP (REST + MCP) through `AgentReadyDataService`
  only. No Spark, no JDBC, no direct table access.
- **Fail-closed, inherited.** A `DENY` from skifer's certification gate is shown as such, never
  bypassed or cached as a success.
- **Dashboards as code.** YAML validated by a JSON Schema, human-editable, agent-generable.
- **LLM optional.** Dashboards, exploration, reporting and KPI packs work without any LLM.
- **Permissive licenses only.** Every dependency is checked at adoption time (see `docs/licenses.md`).

## Planned stack

Next.js / React 19 / Tailwind / shadcn / zustand for the web app, FastAPI for the thin backend
(result cache, scheduler, identity), ECharts as the default renderer behind a renderer-neutral
visualization grammar. Final choices are frozen in the foundation plan.
